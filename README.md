## 🌟 Key Features in Version 3.0

### 1. 5 Intelligent Card Alignment Modes (Collision-Free)
- **🌳 Tree Hierarchy**: Left-to-right parent-to-child horizontal branching with dynamic subtree heights.
- **⭕ Radial Circular Orbit**: Central focus roots surrounded by orbiting child nodes at equidistant angles.
- **🔲 Bento Matrix Grid**: Clean, multi-column masonry grid organizing parents and subnodes with zero overlap.
- **⚡ Neural Force Cluster**: Spring-force physics cluster simulation with collision bounds.
- **🌊 Sequential Timeline Stream**: Alternating horizontal flow sequence tracking chronological research milestones.

### 2. Glass HUD Radar Minimap Overhaul
- Frosted glass HUD with live cluster heatmaps (Roots, Subnodes, Active Focused).
- Quick zoom shortcuts (`[60%]` chip zooms directly to 80% on cards).
- 5 one-click layout mode pills in a dedicated arrangement strip with zero overlap.

### 3. Cyber Command Palette (`Cmd+K` / `Ctrl+K`)
- Spotlight / Raycast-style cyber command bar for keyboard-driven navigation.
- Search cards instantly, switch themes, trigger audio briefings, change layout modes, or toggle SFX without lifting hands from keyboard.

### 4. Cute Voice Audio Description & Customizer
- Speech synthesis briefings with selectable cute, soft, pitch-tuned voice options.
- Customizable speech rate, pitch, and voice profile modal.

### 5. Procedural Web Audio Cyber SFX Engine
- Pure synthetic Web Audio API (`window.AudioContext`) with 0 external sound files needed.
- Tactile feedback: cyber hums, card snap clicks, synth chimes, and electric conduit pulses.

### 6. Real-Time Hardware & CPU Telemetry Terminal (`[>_ CPU]`)
- Cyberpunk interactive shell displaying CPU core count, platform, WebGL GPU renderer, heap memory usage, and live load graph.

### 7. Structure Map Beside View
- Interactive network topology modal displaying parent nodes with glowing highlight badges and connected subnodes showing clean heading chips beside them.

### 8. Progressive Web App (PWA) Offline Engine
- Custom service worker (`sw.js`) enabling sub-50ms offline loading from local cache.

### 9. 3D Holographic Constellation Orbit
- Interactive Three.js particle space with Anime.js kinematics, dark/light ambient modes, and direct in-space card editing.

### 10. Cyber Threat Intelligence & Database Sync
- Live NVD CVE catalog, weaponized exploits, BleepingComputer RSS feeds, SQLite database persistence, and Google Docs/Drive export.
